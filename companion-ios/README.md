# SemOS Companion (iOS)

Native Swift/SwiftUI companion app for SemOS. Implements the phone side of the
pairing protocol from `docs/pairing-v1.md` and provides the foundation for
Phase 18 phone-as-peripheral capabilities.

## Build

This is a Swift Package Manager package. On a Mac with Xcode:

```bash
cd companion-ios
swift build          # macOS host build (for CI / sanity)
swift test           # run crypto tests against Rust reference vectors
```

To build for iOS:

```bash
xcodebuild -scheme SemOSCompanion -destination 'platform=iOS Simulator,name=iPhone 16' build
```

Or open `companion-ios/Package.swift` directly in Xcode.

## Structure

| Path | Purpose |
|---|---|
| `Sources/SemOSCompanion/Crypto/PairingCrypto.swift` | Crockford base32, CRC-16/CCITT, HKDF, HMAC, SAS |
| `Sources/SemOSCompanion/Storage/KeychainIdentity.swift` | Load/create X25519 identity in Keychain |
| `Sources/SemOSCompanion/Network/PairingListener.swift` | `Network.framework` TCP listener + handshake server |
| `Sources/SemOSCompanion/UI/QRCodeView.swift` | QR + base32 string display |
| `Sources/SemOSCompanion/UI/SASView.swift` | SAS match UI |
| `Sources/SemOSCompanion/PairingView.swift` | Main pairing flow |
| `Tests/SemOSCompanionTests/PairingCryptoTests.swift` | Bit-identical KATs against Rust vectors |

## Test vectors

The Swift tests reproduce every intermediate value from
`docs/pairing-v1-test-vectors.md`, which is generated by
`tools/pairing-vectors`. Run `swift test` after any crypto change.
